# Phone_Pay_Dashboard
PhonePe Transaction Analysis Dashboard 📊

This project is an interactive Power BI dashboard created to analyze PhonePe transaction data. It provides insights into transaction trends, transaction amounts, transaction counts, and overall digital payment performance.

🔹 Tools & Technologies
Power BI
DAX
Power Query
Data Visualization
Data Analysis
🔹 Key Features
Transaction amount and transaction count analysis
Monthly and yearly transaction trends
Interactive slicers and filters
State-wise and category-wise analysis
KPI cards for important metrics
Interactive charts and visualizations
User-friendly dashboard design
🎯 Objective

The main objective of this project is to transform transaction data into meaningful visual insights that can help understand payment patterns and trends.

📌 Project Type

Data Analytics | Power BI Dashboard | Business Intelligence
